# Revision 71 Correction Contract

## Goal

Make every immutable R2 source readable through ordinary Windows IDE and PowerShell file surfaces
without weakening source identity, reviewer independence, closed authority, or Windows-only v0.1
support.

## Scope

- Replace path-mirroring reviewer snapshots with deterministic full-SHA-256 aliases.
- Preserve each original repository path, Git object ID, byte count, and digest in the candidate
  manifest.
- Keep reviewer-facing logical snapshot paths at or below 180 characters.
- Reject alias collisions and over-budget logical paths before package compilation.
- Add an exact R70-derived Windows PowerShell readability and byte-authentication regression.
- Rebind only the changed parent and harness identities in the copied lifecycle.
- Preserve the exact R70 hosted, canonical, compilation, package, and handoff evidence.

No V12 product API, scheduler, model, provider, IDE adapter, permission, process, merge, or memory
effect changes. The external host remains responsible for runtime supply and effects.

## Completion Evidence

- Every exact R70 reviewed source materializes below the legacy 260-character Windows boundary in a
  representative 72-character repository root.
- Ordinary Windows PowerShell authenticates every materialized file by existence, byte count, and
  SHA-256 digest.
- Focused, complete review, release-gate, core, checker, static, and dogfood gates pass.
- Independent mutable-source review passes.
- One immutable R71 source passes copied lifecycle, complete verifier, non-consuming rehearsal,
  hosted Template Check and Windows Node 22/24, one canonical gate, and fresh three-domain R2.

## Stop Conditions

- Any source substitution, collision, unreadable path, or identity mismatch emits `fix`.
- Any verified non-pass R2 outcome permanently retires R71.
- The R71 canonical gate may run exactly once and only after all prior immutable and hosted gates
  pass.
