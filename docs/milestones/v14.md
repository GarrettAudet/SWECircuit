# Milestone: V14 Adaptive Orchestration

## Status

Release candidate on `codex/v14-adaptive-orchestration`; exact-candidate qualification active.

## Goal

Turn one software goal into an optimized native IDE specialist run with deterministic
least-sufficient routing, dependency-safe parallel work, verified fan-in, visible decisions,
independent review, and durable memory.

## Shipped

- Closed product, architecture, work-unit, specialist, authority, and evidence contracts.
- Deterministic least-cost feasible model, effort, skill, and tool assignment from host supply.
- Immutable adaptive sessions, typed recovery, strict JSON/Markdown RunView, and owner overrides.
- Windows Codex Desktop host contract with exact native launch, lifecycle, and handoff evidence.
- Small, medium, and high-risk dogfoods with serial baselines, safe fan-out, recovery, and fan-in.
- A hardened release gate that rejects stale, forged, unsafe, widened, or tampered evidence and
  proves two complete replays are byte-identical to the committed preimage.

## Why It Matters

V14 replaces manual agent-role and model selection with a reviewed, deterministic path while
preserving the IDE as the effectful host and one human-visible trace as the source of truth.
