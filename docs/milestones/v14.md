# Milestone: V14 Adaptive Orchestration

## Status

Working Windows alpha on `codex/v14-adaptive-orchestration`; general release qualification active.

## Goal

Turn one software goal into an optimized native IDE specialist run: deterministic
least-sufficient runtime routing, dependency-safe execution, verified fan-in, visible decisions,
independent review, and durable memory.

## Shipped

- Provider-neutral demand and host-supplied runtime inventory contracts.
- Deterministic least-sufficient model and effort routing with hard-gate evidence.
- Immutable adaptive host events, controller inspection, and JSON/Markdown RunView.
- Windows Codex Desktop adapter contract and explicit `AGENTS.md` activation path.
- A real small-goal dogfood with two parallel native specialists using different runtimes.
- Release Board, exact failed-handoff preservation, correction routing, integration, 15 app and evidence tests,
  and source-bound desktop/mobile browser evidence.

## Why It Matters

The repository can now demonstrate the intended interaction inside Codex Desktop: one goal becomes
bounded work, a task-shaped team, least-sufficient runtime assignments, parallel native work,
verified evidence, one integrated application, and a visible trace. The small alpha is usable
without claiming that core performed host effects.
